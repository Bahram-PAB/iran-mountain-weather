# 🏔️ Iran Mountain Weather Bot

ربات پیش‌بینی آب و هوای قله‌های پرتردد ایران

## 📋 توضیحات

این ربات هر هفته در **روزهای سه‌شنبه و چهارشنبه ساعت ۱۶:۳۰** (به وقت ایران)، پیش‌بینی آب و هوای قله‌های معروف ایران رو برای **پنجشنبه و جمعه** از API رایگان Open-Meteo دریافت کرده و به کانال تلگرامی ارسال می‌کند.
آپدیت : زمان بندی به ارسال هر روزه تنظیم شد.

## ⚙️ تنظیمات

### GitHub Secrets (الزامی)

| Secret | توضیح |
|--------|--------|
| `TELEGRAM_BOT_TOKEN` | توکن ربات تلگرام از @BotFather |
| `TELEGRAM_CHAT_ID` | آیدی کانال تلگرامی |

### نحوه دریافت توکن ربات
1. ربات `@BotFather` رو در تلگرام باز کنید
2. دستور `/newbot` رو بزنید
3. نام ربات و یوزرنیم رو وارد کنید
4. توکن دریافتی رو در GitHub Secrets ذخیره کنید

### نحوه دریافت آیدی کانال
1. ربات رو به کانال اضافه کنید (به عنوان ادمین)
2. یه پیام در کانال بفرستید
3. آیدی کانال رو پیدا کنید
