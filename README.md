# 🏔️ Iran Mountain Weather Bot

ربات پیش‌بینی آب و هوای قله‌های پرتردد ایران

## 📋 توضیحات

این ربات هر هفته در **روزهای سه‌شنبه و چهارشنبه**، پیش‌بینی آب و هوای قله‌های معروف ایران رو برای **پنجشنبه و جمعه** از API رایگان Open-Meteo دریافت کرده و به گروه تلگرامی ارسال می‌کند.

## 🎯 ویژگی‌ها

- ✅ پیش‌بینی آب و هوا برای ۲۰ قله پرتردد ایران
- ✅ ارسال خودکار در سه‌شنبه و چهارشنبه
- ✅ استفاده از API رایگان Open-Meteo (بدون نیاز به API Key)
- ✅ نمایش دما، بارش، برف، باد و کد آب و هوا
- ✅ محاسبه بر اساس ارتفاع هر قله
- ✅ پشتیبانی از GitHub Actions برای اجرای خودکار

## ⚙️ تنظیمات

### GitHub Secrets (الزامی)

| Secret | توضیح |
|--------|--------|
| `TELEGRAM_BOT_TOKEN` | توکن ربات تلگرام از @BotFather |
| `TELEGRAM_CHAT_ID` | آیدی گروه تلگرامی |

### نحوه دریافت توکن ربات
1. ربات `@BotFather` رو در تلگرام باز کنید
2. دستور `/newbot` رو بزنید
3. نام ربات و یوزرنیم رو وارد کنید
4. توکن دریافتی رو در GitHub Secrets ذخیره کنید

### نحوه دریافت آیدی گروه
1. ربات رو به گروه اضافه کنید
2. توی گروه یه پیام بفرستید
3. آیدی گروه رو پیدا کنید (مثلاً از `@userinfobot`)

## 🚀 نحوه اجرا

### خودکار (GitHub Actions)
- **سه‌شنبه ساعت ۸ صبح** → پیش‌بینی پنجشنبه
- **چهارشنبه ساعت ۸ صبح** → پیش‌بینی جمعه

### دستی
```bash
python3 bot.py
```
